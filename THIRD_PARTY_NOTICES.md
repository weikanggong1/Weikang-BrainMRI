- `synthstrip/` adapts FreeSurfer's `mri_synthstrip`, by Andrew Hoopes, Jocelyn S. Mora, Adrian V. Dalca, Bruce Fischl, Malte Hoffmann and collaborators. The original implementation already uses PyTorch. Preserve the accompanying FreeSurfer license (`licenses/FreeSurfer.txt`).
- `synthmorph/pipeline.py` and the image-space workflow adapt FreeSurfer's SynthMorph registration code by Malte Hoffmann and collaborators. Preserve the accompanying FreeSurfer license.
- `synthmorph/models.py` and `synthmorph/spatial.py` implement VoxelMorph/Neurite algorithms, originally distributed under Apache License 2.0 (`licenses/Apache-2.0.txt`). Modified for PyTorch, channels-first tensors, direct HDF5 loading, and reusable inference.
- `wmh_synthseg/` adapts the inference workflow and 3D U-Net of FreeSurfer's `mri_WMHsynthseg` (FreeSurfer 8.2.0-1) under the FreeSurfer Software License (`licenses/FreeSurfer.txt`).
- `synthsr/` adapts FreeSurfer's `mri_synthsr` single-input inference pipeline and 3D U-Net for PyTorch. The source workflow, orientation and resampling rules, and official HDF5 checkpoints are attributed to the FreeSurfer authors. This adaptation is marked as modified and retains the FreeSurfer Software License (`licenses/FreeSurfer.txt`). The legacy two-input `mri_synthsr_hyperfine` program is separate and is not implemented here.
- `fast/` is a modified PyTorch implementation of FAST's single-channel T1, three-tissue HMRF-EM segmentation, partial-volume estimation and bias-field correction. The reference was FAST4 tag `2111.3`, Copyright University of Oxford. The complete FSL 6.0 license is in [`licenses/FSL-6.0.txt`](licenses/FSL-6.0.txt); its non-commercial-use terms apply. Under that license's source-transmission condition, the complete, unmodified source tree from the FAST4 tag is distributed with this adaptation in [`src/freesurfer_torch/fast/upstream_fast4/`](src/freesurfer_torch/fast/upstream_fast4/). It is retained for licensing and provenance and is not compiled or imported by this package. The PyTorch source is distributed alongside it and does not claim bitwise equivalence.
- `src/freesurfer_torch/fast_vbm/` combines SynthStrip brain extraction, TorchFAST tissue estimation, an independently written PyTorch FLIRT-compatible 12-DOF affine, and the package's PyTorch SynthMorph `deform` model. The linear implementation uses normalized-correlation and Adam optimization; it contains no FSL FLIRT source, has no FSL FLIRT binary runtime dependency, and is not represented as algorithmically equivalent to FSL FLIRT. The nonlinear stage loads the official `synthmorph.deform.3.h5` checkpoint through this package and applies the supplied affine with `mid_space=False`; it does not call FNIRT and is not represented as FNIRT-equivalent. The subject-level order is informed by `bb_struct_init` and `bb_vbm` in the [UK Biobank brain imaging pipeline v1.5](https://git.fmrib.ox.ac.uk/falmagro/uk_biobank_pipeline_v_1.5), Copyright 2021 University of Oxford and distributed upstream under Apache License 2.0 (`licenses/Apache-2.0.txt`). The FreeSurfer license applies to the SynthStrip and SynthMorph workflow adaptations, the VoxelMorph/Neurite Apache 2.0 notice applies to the SynthMorph network algorithms, and the FSL 6.0 terms described above apply to TorchFAST.

The corresponding model architecture in this package retains that attribution and license; the complete license is in [`licenses/pytorch-3dunet-MIT.txt`](licenses/pytorch-3dunet-MIT.txt), copied from the [upstream license](https://github.com/wolny/pytorch-3dunet/blob/master/LICENSE).
