- `synthstrip/` adapts FreeSurfer's `mri_synthstrip`, by Andrew Hoopes, Jocelyn S. Mora, Adrian V. Dalca, Bruce Fischl, Malte Hoffmann and collaborators. The original implementation already uses PyTorch. Preserve the accompanying FreeSurfer license (`licenses/FreeSurfer.txt`).
- `synthmorph/pipeline.py` and the image-space workflow adapt FreeSurfer's SynthMorph registration code by Malte Hoffmann and collaborators. Preserve the accompanying FreeSurfer license.
- `synthmorph/models.py` and `synthmorph/spatial.py` implement VoxelMorph/Neurite algorithms, originally distributed under Apache License 2.0 (`licenses/Apache-2.0.txt`). Modified for PyTorch, channels-first tensors, direct HDF5 loading, and reusable inference.
- `wmh_synthseg/` adapts the inference workflow and 3D U-Net of FreeSurfer's `mri_WMHsynthseg` (FreeSurfer 8.2.0-1) under the FreeSurfer Software License (`licenses/FreeSurfer.txt`).
- `synthsr/` adapts FreeSurfer's `mri_synthsr` single-input inference pipeline and 3D U-Net for PyTorch. The source workflow, orientation and resampling rules, and official HDF5 checkpoints are attributed to the FreeSurfer authors. This adaptation is marked as modified and retains the FreeSurfer Software License (`licenses/FreeSurfer.txt`). The legacy two-input `mri_synthsr_hyperfine` program is separate and is not implemented here.
- `fast/` is a modified PyTorch implementation of FAST's single-channel T1, three-tissue HMRF-EM segmentation, partial-volume estimation and bias-field correction. The reference was FAST4 tag `2111.3`, Copyright University of Oxford. The complete FSL 6.0 license is in [`licenses/FSL-6.0.txt`](licenses/FSL-6.0.txt); its non-commercial-use terms apply. Under that license's source-transmission condition, the complete, unmodified source tree from the FAST4 tag is distributed with this adaptation in [`src/freesurfer_torch/fast/upstream_fast4/`](src/freesurfer_torch/fast/upstream_fast4/). It is retained for licensing and provenance and is not compiled or imported by this package. The PyTorch source is distributed alongside it and does not claim bitwise equivalence.
- `src/freesurfer_torch/fast_vbm/` combines SynthStrip brain extraction, TorchFAST tissue estimation, affine registration, and a selectable nonlinear registration backend. The SynthMorph branch uses the official `synthmorph.deform.3.h5` checkpoint through this package. The subject-level sequence is informed by `bb_struct_init` and `bb_vbm` in the [UK Biobank brain imaging pipeline v1.5](https://git.fmrib.ox.ac.uk/falmagro/uk_biobank_pipeline_v_1.5), Copyright 2021 University of Oxford and distributed upstream under Apache License 2.0 (`licenses/Apache-2.0.txt`). The FreeSurfer licence applies to the SynthStrip and SynthMorph workflow adaptations, and the VoxelMorph/Neurite Apache 2.0 notice applies to the SynthMorph network algorithms.
- `src/freesurfer_torch/flirt/`, `src/freesurfer_torch/fnirt/`, and `src/freesurfer_torch/applywarp/` are modified Python/PyTorch ports derived from the FSL FLIRT, FNIRT, basisfield, miscmaths, newimage, warpfns, and fugue source code. They are subject to the non-commercial FSL Software Licence, Release 6.0 (`licenses/FSL-6.0.txt`) and are not an official FSL release. Complete, unmodified upstream source trees for every referenced component are distributed in `src/freesurfer_torch/_vendor_fsl/sources/`; the modified Python source is distributed alongside them. `src/freesurfer_torch/_vendor_fsl/manifest.json` records repositories, tags, commits, Git trees, archive hashes, and per-file SHA-256 values. FSL 6.0.7.4 comparisons use FLIRT 2111.2, FNIRT 2203.0, basisfield 2203.1, miscmaths 2203.2, newimage 2203.11, warpfns 2203.0, and fugue 2201.3. The separate fugue 2603.0 snapshot records a checkout inspected during development and is not the numerical validation target. Numerical compatibility claims are limited to the validation results published for each function.
- `synthseg_parc/` and `recon_all/gpu_tools.py` adapt FreeSurfer 8.2's [SynthSeg 2.0 `mri_synthseg` implementation](https://github.com/freesurfer/freesurfer/blob/dev/mri_synthseg/mri_synthseg), including its network, image preparation, posterior filtering, and soft-volume reporting, for PyTorch. The adapted code is subject to the FreeSurfer Software License (`licenses/FreeSurfer.txt`).
- `recon_all/sclimbic.py` adapts the network and processing methods of FreeSurfer's [`mri_sclimbic_seg`](https://github.com/freesurfer/freesurfer/blob/dev/mri_sclimbic_seg/mri_sclimbic_seg); `recon_all/aux_seg.py` also follows the FreeSurfer 8.2 EntoWM, MCA/dura, and venous-sinus auxiliary segmentation workflows. These adaptations are subject to the FreeSurfer Software License (`licenses/FreeSurfer.txt`). See the [official ScLimbic documentation](https://surfer.nmr.mgh.harvard.edu/fswiki/ScLimbic).
- `recon_all/standalone.py` and `tools/recon_all_native/` prepare and run a scoped, modified package of FreeSurfer 8.2's [`recon-all` pipeline](https://github.com/freesurfer/freesurfer/blob/d932c45/scripts/recon-all), native executables, scripts, and data. The original `recon-all` script credits Doug Greve and MGH. The PyTorch launchers and bundle tooling are independent modifications; they are not an official FreeSurfer release. FreeSurfer portions remain subject to the FreeSurfer Software License (`licenses/FreeSurfer.txt`).
- `validation/recon_all/native_cuda_pilot/` is an isolated CUDA experiment adapting the intensity-gradient formula in FreeSurfer 8.2's `utils/mrisurf_compute_dxyz.cpp` at commit `d932c45`. It is not used by the published recon-all entry and remains subject to the FreeSurfer Software License (`licenses/FreeSurfer.txt`).
