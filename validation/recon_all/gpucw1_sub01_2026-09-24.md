# Scoped FreeSurfer 8.2 recon-all validation: one T1

On 2026-09-24, the frozen GPU/native bundle completed one public T1 on
`gpucw1`. The input was `examples/data/sub-01_T1w.nii.gz` (SHA-256
`f20410a4efd8e6a05cd04d55730a4a5492ecf9ad1b234fe0fd4661e448270c6a`).
The reference used the installed FreeSurfer 8.2.0-1 implementation. The
candidate used profile `fs820-single-t1-v8-all-v1`, a clean `env -i` launch,
the package's six PyTorch neural replacements, and bundled native programs.
The package Python source tree was frozen before the run at SHA-256
`7a97b9922af20044e57d6e8e2d1b2f19ef8a9ae44ce00e0f22a618b7d8c3cb2b`.

The candidate exited 0 after **3,881.712 s** with all mandatory outputs.
The reference's earlier run took 4,724 s, but its parallel flags and node
conditions differed. These two times do not establish a speedup; a matched
serial A→C benchmark was started separately.

The left and right surfaces contain 106,622 and 105,541 vertices. Every ROI
stats row and global Measure passed its field-specific bound. SynthSeg soft
volumes are not bitwise identical: eTIV differs by +464.8 mm³ (allowed
1,290.2942 mm³) and CSF by +285.7475 mm³ (allowed 356.91094 mm³). The
duplicated `aseg.stats` sTIV Measure differs by +464.8 mm³ and uses the same
soft-volume bound after an explicit profile amendment. Its earlier exact-default failure and the
explicit tolerance amendment are documented in the [criteria](README.md).

The bundle was promoted to `standalone_verified=true` only after a fresh
308-file linkage/resource preflight, a completed run, the 52+2+19 numerical
gates, exact code/version and input checks, output hashes, and a full file/exec
trace audit. The audit saw 89,479 successful open/exec records, including
1,027 bundle executions, and no successful visible access to an external
FreeSurfer/FSL/TensorFlow path. It cannot reconstruct arbitrary relative
cwd/dirfd targets. The host still has an installed FreeSurfer copy; this
scoped trace is evidence of package-owned runtime use, not a clean-host trial.
